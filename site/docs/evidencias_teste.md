# Evidências e Testes do Projeto

## 1. Objetivo

Este documento registra os testes planejados e realizados durante o desenvolvimento do site sobre sustentabilidade e impacto social.

O objetivo é verificar a navegação, a organização das páginas, a acessibilidade e a validade do código HTML.

## 2. Testes de navegação

**Procedimento:**
- Abrir a página inicial do site.
- Clicar nos links do menu.
- Verificar se as dez páginas podem ser acessadas.
- Verificar se os links para voltar à página inicial funcionam.
- Conferir se os links não direcionam para arquivos inexistentes.

**Status:** Pendente de verificação.

**Evidência:** Registrar capturas de tela após realizar os testes.

## 3. Testes de acessibilidade

**Procedimento:**
- Verificar se as imagens possuem textos alternativos adequados.
- Conferir se os campos dos formulários possuem rótulos.
- Verificar se os títulos seguem uma hierarquia organizada.
- Testar a navegação utilizando a tecla Tab.
- Conferir se os textos apresentam contraste adequado com o fundo.
- Verificar se o documento HTML utiliza o idioma português do Brasil.

**Status:** Pendente de verificação.

**Evidência:** Registrar os resultados das verificações e eventuais correções.

## 4. Validação do HTML

A validação deve ser realizada por meio do serviço W3C Markup Validation Service.

**Procedimento:**
1. Acessar https://validator.w3.org/.
2. Selecionar a opção para validar por envio de arquivo.
3. Selecionar cada arquivo HTML do projeto.
4. Executar a validação.
5. Registrar erros e avisos encontrados.
6. Corrigir os problemas identificados e repetir os testes.

**Status:** Pendente de validação.

## 5. Teste do formulário de contato

**Procedimento:**
- Verificar se os campos obrigatórios impedem o envio quando estão vazios.
- Inserir um e-mail inválido para verificar a validação.
- Conferir os campos que utilizam formatos específicos.
- Verificar se os rótulos dos campos estão identificados corretamente.

**Status:** Pendente de verificação.

## 6. Organização das evidências

As capturas de tela e outros registros dos testes deverão ser armazenados em uma pasta de evidências, preferencialmente dentro da pasta `docs`.

Sugestão de organização:

- `docs/evidencias/` — capturas de tela dos testes.
- `docs/evidencias_testes.md` — descrição dos procedimentos e resultados.

## 7. Conclusão

Os testes são importantes para verificar o funcionamento do site e identificar problemas antes da entrega.

Após a execução dos procedimentos, este documento deverá ser atualizado com os resultados reais, os problemas encontrados e as correções realizadas.
