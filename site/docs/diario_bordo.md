# Diário de Bordo — Desenvolvimento do Projeto

## 1. Início do projeto

O projeto foi iniciado com o objetivo de desenvolver um site sobre sustentabilidade e impacto social, aplicando os conhecimentos adquiridos na disciplina de Front-End.

## 2. Planejamento e organização

Foi definida a criação de dez páginas HTML interligadas, cada uma com uma finalidade específica. Também foi criada a pasta `docs` para organizar a documentação do projeto.

## 3. Desenvolvimento

Durante o desenvolvimento, foram criadas as páginas HTML e organizada a estrutura dos arquivos no Visual Studio Code.

## 4. Aprendizados

- Organização de arquivos e pastas em um projeto web.
- Criação de páginas utilizando HTML.
- Importância da navegação entre páginas.
- Organização e documentação de um projeto.
- Importância da acessibilidade em sites.

## 5. Dificuldades encontradas

Durante a organização do projeto, surgiram dúvidas sobre a criação de pastas e arquivos no Visual Studio Code e sobre a extensão correta dos documentos.

Essas dificuldades foram trabalhadas com orientação e execução passo a passo.

## 6. Próximas etapas

- Revisar os links entre as dez páginas.
- Verificar a organização dos arquivos.
- Pesquisar opções de hospedagem e registro de domínio.
- Realizar testes de navegação e acessibilidade.
- Finalizar a documentação do projeto.

## 7. Observação

Este diário deve ser atualizado conforme o projeto avançar, registrando as decisões, os problemas reais encontrados e as soluções aplicadas.
