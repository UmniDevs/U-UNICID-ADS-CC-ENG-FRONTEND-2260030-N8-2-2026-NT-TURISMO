# Projeto de Site — Sustentabilidade e Impacto Social

## 1. Sobre o projeto

Este projeto foi desenvolvido como parte da atividade A2 da disciplina de Front-End do curso de Análise e Desenvolvimento de Sistemas da Universidade Cidade de São Paulo (UNICID).

O objetivo é desenvolver um site utilizando HTML5, com páginas interligadas, organização de conteúdo, navegação intuitiva e recursos de acessibilidade.

## 2. Objetivo

Apresentar informações sobre sustentabilidade e impacto social, destacando iniciativas, projetos, resultados e práticas que contribuam para a conscientização da sociedade.

## 3. Estrutura do site

O site é composto por dez páginas:

1. `index.html` — Página inicial.
2. `sobre.html` — Apresentação do projeto.
3. `projetos.html` — Projetos de sustentabilidade e impacto social.
4. `impacto.html` — Dados e resultados.
5. `acessibilidade.html` — Recursos de inclusão e acessibilidade.
6. `galeria.html` — Galeria de imagens.
7. `midia.html` — Conteúdos multimídia.
8. `noticias.html` — Notícias e artigos.
9. `contato.html` — Formulário de contato.
10. `orcamento_hospedagem.html` — Comparação de hospedagem e domínios.

## 4. Tecnologias utilizadas

- HTML5 para a estrutura das páginas.
- CSS3 para a apresentação visual, caso utilizado no projeto.
- Visual Studio Code como editor de código.
- GitHub para armazenamento e versionamento do projeto.

## 5. Acessibilidade

O projeto busca utilizar uma estrutura semântica, textos alternativos para imagens, formulários com identificação dos campos e navegação clara, visando facilitar o acesso ao conteúdo por diferentes usuários.

## 6. Organização dos arquivos

As páginas HTML ficam na pasta principal do site. A pasta `docs` reúne os documentos de planejamento, registro do desenvolvimento, orçamento e testes do projeto.

## 7. Considerações finais

O desenvolvimento permite aplicar os conhecimentos de HTML5, organização de arquivos, navegação entre páginas e boas práticas de acessibilidade, além de abordar temas relacionados à sustentabilidade e ao impacto social.
